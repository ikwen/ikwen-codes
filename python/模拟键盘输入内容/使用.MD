python 脚本，读取一个文件的内容，然后延迟5秒，把文件的内容用模拟键盘输入到那个不能粘贴的终端。

安装依赖
首先需要安装必要的Python库：

bash
pip install pyautogui pynput pyperclip
使用方法
准备要输入的文件，比如 my_text.txt

运行脚本：

bash
python type_file.py my_text.txt
操作流程：

脚本会读取文件内容并显示预览

显示5秒倒计时

倒计时结束后，

脚本会自动将文件内容输入到该窗口

直接模拟键盘：逐字符输入，适合纯英文和数字

如果需要切换方式，在 main() 函数中取消注释或注释相应的函数调用。

注意事项
确保目标窗口已经准备好接收输入

某些终端可能需要等待命令提示符出现

如果内容包含特殊字符（如 $, \, " 等），

输入过程中不要移动鼠标或按键盘

某些终端可能需要管理员权限才能模拟输入
