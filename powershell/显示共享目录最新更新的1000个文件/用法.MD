#进入网络目录：
Set-Location -LiteralPath '\\192.168.0.68\工具房\[ [ [ 胶板 ] ] ]'
(把 \\192.168.0.68\工具房\[ [ [ 胶板 ] ] ] 换成你的。)

Get-ChildItem -Recurse | Where-Object { !$_.PSIsContainer } | Sort-Object LastWriteTime -Descending | Select-Object -First 1000  > C:\Users\ww\Desktop\李少通\50.txt

输出结果：（把  C:\Users\ww\Desktop\李少通\50.txt  换成你的。）


常用命令，读取共享目录，显示最新更新的1000个文件，方便知道同事正在修改哪些文件。
